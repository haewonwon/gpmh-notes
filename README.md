# gpmh-notes

취업 준비뿐만 아니라 지속적인 학습을 위한 작업 공간입니다. 실습이 필요해지면 추후 `gpmh-labs`를 생성할 예정입니다.
자격증 취득 준비 시, 루트에 `certifications/`를 추가합니다.

## 구조

| 폴더                   | 범위                                              |
| ---------------------- | ------------------------------------------------- |
| [frontend/](frontend/) | 브라우저, React/Next, 상태관리, 번들링 등         |
| [backend/](backend/)   | API, 서버, 인증, BFF 등                           |
| [cs/](cs/)             | 자료구조, 알고리즘, OS, 네트워크, DB, 컴퓨터 구조 |
| [js/](js/)             | 스코프, 클로저, 비동기, 이벤트 루프 등            |
| [ts/](ts/)             | 타입, 제네릭, 유틸리티 타입 등                    |

## 커밋 규칙

| prefix | 언제                             |
| ------ | -------------------------------- |
| `add`  | 학습 내용(노트)을 새로 추가할 때 |
| `fix`  | 이미 있는 내용을 고칠 때         |
| `docs` | README를 추가하거나 수정할 때    |

예시: `add: 클로저 정리`, `docs: 루트 README 커밋 규칙 추가`, `fix: 이벤트 루프 설명 수정`
