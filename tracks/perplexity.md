# Perplexity에서 공부할 때

페이지 작성은 Codex 또는 Claude Code가 한다. Perplexity는 이미 써 둔 노트를 공부할 때 쓴다.
새 학습 페이지를 작성하지 않는다. 노션을 수정하지 않는다. Computer로 파일을 만들지 않는다.

비공개 노션 페이지는 링크만으로 읽히지 않는다. 공부할 때는 노트에서 해당 부분을 붙여 넣는다.
웹에 게시한 페이지만 주소로 열린다.

Space 하나에 지금 공부하는 트랙 파일을 지침으로 둔다.

- Track A: `a-language-backend.md`
- Track B: `b-frontend.md`
- Track C: `c-computer-networks.md`

그 파일의 "아직 배우지 않은 개념" 규칙과 이해도 질문 피드백 형식을 따른다.
사용자가 붙인 노트 범위를 벗어나서 커리큘럼의 다음 주제를 설명하지 않는다.
사실 확인이 필요하면 그 트랙의 1차 출처를 연다.

## 요청 템플릿

설명을 물을 때:

```text
트랙: A
이미 배운 범위: 스코프, 함수
아직 배우지 않은 범위: 이벤트 루프, 모듈

아래 노트의 이 부분이 이해되지 않아. 이 노트 범위 안에서 설명해 줘.

(노트에서 해당 부분만 붙여 넣기)
```

이해도 질문에 답할 때:

```text
트랙: A
아직 배우지 않은 범위: 이벤트 루프, 모듈

이해도 질문에 이렇게 답했어.
맞은 부분, 틀린 부분, 정확한 근거, [복습 필요]로 나눠 줘.

(질문과 내 답)
```

노트와 다른 설명이 필요하거나 글 자체를 고치고 싶으면 Perplexity에서 끝내지 않는다.
Codex 또는 Claude Code로 돌아와서 저장소와 노션을 같이 수정한다.
